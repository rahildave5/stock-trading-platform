# Stock Trading Platform

A full-stack fintech web application inspired by the core UX of Zerodha Kite. It allows users to track real-time stock prices, manage a virtual portfolio, analyze charts, and execute mock trades in a seamless, minimalist interface.

🚀 Features
1. User Authentication & Security
Secure signup and login using JWT (JSON Web Tokens) or OAuth.

Two-factor authentication (2FA) simulation (e.g., TOTP or PIN) mimicking Kite's login flow.

2. Real-Time Dashboard & Watchlist
Dynamic, real-time stock price streaming using WebSockets.

Personalized watchlists where users can add, remove, and track their favorite tickers.

3. Trading & Portfolio Management
Order Execution: Support for Market, Limit, and MIS/CNC (Intraday/Delivery) order types.

Holdings & Positions: Separate tabs to track long-term investments (Holdings) vs. active day trades (Positions).

Funds Management: Virtual wallet to add or withdraw funds for mock trading.
Live search bar with auto-suggest for stocks and indices (NIFTY 50, SENSEX).
